## Выбранная СУБД
H2 (встроенная база данных, работающая в режиме in-memory).

## Порядок подготовки базы данных
База данных создается автоматически при запуске программы в памяти (`jdbc:h2:mem:testdb`). Никакой дополнительной установки СУБД не требуется. Скрипт `music-create.sql` и файл `books.json` читаются программой автоматически из корня проекта.
